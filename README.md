# דף נחיתה – חבילה מוכנה ל-Render

זהו אתר סטטי, ללא שלב build.

## העלאה ל-Render
1. העלו את תוכן התיקייה לריפוזיטורי GitHub.
2. ב-Render בחרו **New > Static Site** וחברו את הריפוזיטורי.
3. Build Command: `echo "Static site - no build"`
4. Publish Directory: `.`
5. צרו את האתר.

## קבצים חשובים
- `index.html` – עמוד הכניסה לאתר
- `support.js` – מנוע ההרצה של הייצוא מ-Claude Design
- `_ds/` – עיצוב ורכיבי Design System

## הערה חשובה על השאלון
כפתור "שליחת השאלון" בגרסה המקורית רק מציג מסך תודה בדפדפן. הוא עדיין לא שולח את התשובות למייל, למסד נתונים או לשרת. כדי לקבל את התשובות בפועל צריך לחבר endpoint / שירות טפסים.
